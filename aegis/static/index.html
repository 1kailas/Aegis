Aegis CLI Quick Reference

      
    

    

      

        

          

            
aegis status

            
Fast terminal dashboard of health, guardians, cluster, and incidents

          

          
        

        

          

            
aegis agent --server http://<server-ip>:8000

            
Start worker node telemetry daemon reporting into cluster mesh

          

          
        

        

          

            
aegis nodes list

            
List all registered cluster nodes, statuses, and capacities

          

          
        

        

          

            
aegis nodes drain <node-id>

            
Cordon and drain a node before maintenance

          

          
        

        

          

            
aegis models recommend

            
Profile host hardware and rank optimal vs worst AI models

          

          
        

        

          

            
aegis models benchmark <model-name>

            
Run empirical Time-To-First-Token and token throughput benchmark

          

          
        

        

          

            
aegis models deploy <model> --runtime docker

            
One-click launch with optimal layer offloading

          

          
        

        

          

            
aegis canary rollback <rollout-id>

            
Immediately abort and revert an active canary deployment

          

          
        

        

          

            
aegis keys create --name worker --role NODE_AGENT

            
Generate cryptographically hashed RBAC token

Destructive operations like rm -rf /, pipe injection, or credential tampering are unconditionally rejected with 403 Forbidden.
