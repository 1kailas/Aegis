Aegis Developer CLI & API Reference

      
    

    

      

        

          

            
aegis status

            
Fast terminal dashboard of health, guardians, cluster and incidents

          

          
        

        

          

            
aegis agent --server http://<server-ip>:8000

            
Run worker node telemetry daemon reporting into cluster mesh

          

          
        

        

          

            
aegis nodes list

            
List all registered cluster nodes, statuses, and capacities

          

          
        

        

          

            
aegis nodes drain <node-id>

            
Cordon and drain a node before maintenance

          

          
        

        

          

            
aegis incidents list

            
List all detected, contained, or repairing incidents

          

          
        

        

          

            
aegis incidents diagnose <incident-id>

            
Trigger multi-tier local and cloud AI root-cause diagnosis

          

          
        

        

          

            
aegis canary rollback <rollout-id>

            
Immediately abort and revert an active canary deployment

          

          
        

        

          

            
aegis keys create --name my-worker --role NODE_AGENT

            
Generate cryptographically hashed RBAC token
